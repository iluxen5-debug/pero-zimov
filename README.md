# pero-zimov

PERO Заказы — приложение для ввода и управления заказами поверх Google-таблицы «УФА ОБЩАЯ».

- `index.html`, `manifest.json` — обёртка для телефона (PWA): открывает веб-приложение Apps Script во весь экран.
- `apps-script/Code.gs` — серверная часть (вставляется в редактор Apps Script, файл `Code.gs`).
- `apps-script/index.html` — интерфейс (вставляется в редактор Apps Script, файл `index`).

## Как обновить приложение

1. Таблица → Расширения → Apps Script.
2. Замените содержимое `Code.gs` и `index` файлами из папки `apps-script/`.
3. Сохраните, затем «Развертывание → Управление развертываниями → ✏️ → Версия: Новая → Развернуть».
   Ссылка на приложение при этом не меняется.

## Цены

Цена подставляется из листа, название которого указано в `PRICE_SHEET_NAME` в начале `Code.gs`
(сейчас «Прайс с 05.10.2026»; колонка A — наименование, B — цена).
Если название модели в «Справочниках» отличается от прайса, добавьте пару в `PRICE_ALIASES`.
